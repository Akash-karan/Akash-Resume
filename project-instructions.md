# Project Instructions

## Overview
I'm planning to create a website for myself. I have designed the whole website for all versions — desktop, tablet, and mobile.

## Tech Stack
Build the website using the **Next.js** framework.

## Approach
- I will provide the Figma design link section by section, covering all versions (desktop, tablet, mobile) for that section.
- Build only the section provided — do not move ahead to the next section on your own.
- Once all aspects of the current section are completed and confirmed, I will ask you to build the next section in the same manner.
- Repeat this process section by section until the website is complete.

## Design Consistency
- All design system elements and design styles used in development should match the Figma design exactly.
- Maintain consistency in spacing, typography, colors, and components across all sections and screen sizes as defined in Figma.
